# 评估方法与使用

评估分为**实现正确性、条件是否被利用、生成质量与泛化**三层。loss下降或程序成功只能回答其中一部分。

## 1. 先核验实现

- 训练前零输出与训练后scale0/active0预测应与原生一致。
- 主干参数不更新；适配器输出投影出现有限非零梯度。
- checkpoint重算与直接前向的梯度一致，padding不干扰有效token。
- 保存重载、恢复学习率与采样顺序、global batch不整除卡数时的梯度加权都要验证。

这些在 `tests/` 中有实际小模型测试；目标GPU还需真实权重的3步预检。
若使用改动过的原生后端，先做数值核验，避免把接口bug解释成风格学习困难。

## 2. 数据隔离与配对生成

训练目标与参考：同画师、不同作品族；dev/test作品族与train分开。评估时再把**输入参考**和
**评分图库**的作品族分开。仅换文件名或切裁图不算独立作品。
“adapter-unseen”仅说明适配器没训练过这些画师，不能推断Kaloscope或生成模型预训练也未见。

冻结画师、内容、prompt、seed、分辨率、参考、检查点和采样日程。每个案例至少包含：

1. 原生/关闭风格 U；
2. 正确参考；
3. 错误画师参考，guidance和scale与正确参考完全相同。

按已见/未见画师、尺寸和宽高比分组，避免总体均值掩盖未见组退化。
复用同一个原生PNG可以降低计算成本，但不是多次独立生成；保存SHA并报告唯一输出数。
单画师多个内容/seed不是多个独立画师。早期16画师图库、Z3C的8画师图库、Moss的48画师图库
难度不同，Hit@1不能横向直接排名。

## 3. 风格指标

**Kaloscope目标风格余弦 / Hit@1**：生成图的归一化256D projector 与评分参考原型做余弦。
Hit@1是在当前图库内，目标画师原型是否最高。不是大规模分类头准确率，也不是人类质量率。
它与训练条件编码器同源，可能偏向“编码器能看出的风格”，应作为诊断，不独立裁决成功。

**相对增益 L**：`cos(g_style,r) − cos(g_native,r)`，排除原模型恰好已有某种外观的影响。
早期架构实验的 **D**：固定目标参考r_i，正确条件输出g_i的相似度，减去其他画师条件输出g_j的均值。
后期v2的 **margin** 是固定输出g_i，目标参考原型r_i的相似度减去其他参考原型r_j的均值。
两者比较对象不同，不应仅因为都叫“正确减错误”就混为一列。

**独立 CSD**：使用与条件编码器不同的风格表征，目标相似度、图库Hit@1、margin一起看。
独立仅指不与训练条件同源，不能保证完全消除内容偏差。源码来源为
[CSD研究仓库](https://github.com/learn2phoenix/CSD)。

本包提供 `kaloscope_style.evaluate`：

```bash
python -m kaloscope_style.evaluate \
  --panel examples/evaluation_panel.json \
  --encoder models/z3_artist_v1 \
  --output runs/eval_kaloscope.json

python -m kaloscope_style.evaluate \
  --panel examples/evaluation_panel.json \
  --encoder models/z3_artist_v1 --csd-root models/csd \
  --anchor runs/eval_baseline.json --output runs/eval_candidate.json
```

示例面板只有2画师用于展示格式；`--anchor` 的画师聚类区间至少需4画师，正式评估应扩展至16或更多。
`cases` 的id必须在候选/基线中一一相同，prompt/seed与参考身份由面板构建者保持一致；
每行提供生成图、输入参考路径、目标画师及area/aspect/cohort。`gallery`是每画师独立评分参考列表。
程序检查直接文件路径复用，**作品族/近重复隔离仍需上游审计**。

CSD资产布局：

```text
models/csd/
  csd-vit-l.bin
  vendor/CSD/models/clip/model.py
```

沿用历史v2的固定SHA256，避免“同名权重”造成漂移：

- `models/clip/model.py`：`889337fd6ba71672bb26c9b8927dcf07fdb2dbb49b7d4cb94c10b00e0dfc386e`
- `csd-vit-l.bin`：`40e92fad63a361b8136100cd234c42d401ef9b34ff1748234318929ebcc7e7a1`

权重不附带本包，从原实验资产或CSD作者发布渠道准备并核对哈希。
若另换权重或结构，必须声明新的评估协议并重新给基线评分，不能直接删掉校验混用结果。

长图采用长轴起点/中心/终点三张重叠方形裁切，生成图和评分参考**对称处理**；
CSD每视图224，Kaloscope每视图512，各视图归一化后均值再归一化。
这改善只看中心或letterbox的偏差，但不会完整表达布局。方图三个视图相同，不能把它们计作3张独立样本。
macro按area/aspect/artist单元先均值，再单元等权；按画师、cohort、尺寸和比例拆分结果。
这是v2口径，不会重现早期中心裁图的全部绝对分数。

## 4. 固定 flow-matching 验证

训练入口每 `eval_every` 步在固定dev目标、第一参考、固定噪声/σ下计算：

- `correct_fm`：正确参考的MSE。
- `off_fm`：同一输入关闭风格的MSE。
- `wrong_fm`：同一输入换错误画师参考的MSE。
- `condition_gain=(off−correct)/off`。
- `correct_vs_wrong=(wrong−correct)/off`。

每次用相同目标、噪声、时间、内容文本，关闭dropout；正确和错参考强度一致。
训练滚动loss的样本不断变动，不能代替固定FM验证。
FM小幅改善说明帮助预测速度，不等于正确画师外观、结构正常或文字正确。
本包的简化固定方图dev协议与历史多分辨率288案例协议是不同面板，不能直接比较绝对值。

## 5. 内容、泄漏与人工质量

历史内容余弦来自未经画师微调的原始DINO全局特征，比输出与内容源图；只作img2img内容诊断。
它不是姿态/属性准确率，不是参考内容复制率。目标画师的常见服装/人物与风格高度相关，
输入参考相似度变高也可能是内容复制，需要直接观察。
本包当前评分CLI实现Kaloscope/CSD，不自动复刻旧raw-DINO内容分支、CLIP-T或姿态评价；
历史这些列只作为原记录保留。新增内容指标时需独立模型、独立基线和新协议标识。

建议匿名打乱A/B、按画师和对照平衡左右位置，包含重复题，分别记录：
风格接近度、内容/构图保持、参考人物或物体复制、手部/线条/纹理破坏、文字/符号异常。
“未评价/无法判断”必须单列；不能当作平局或成功。
同一用户的重复或修订反馈不重复计票。单人开发反馈不能冒充多人盲评偏好率。

## 6. 不确定性与停止规则

`paired_ci`按画师聚类重采样2000次，先聚合同一画师的尺寸/比例单元，再给出配对差的95%百分位区间。
不把crop、同参考多seed或复用PNG当作独立画师；拒绝不一致的case IDs/元数据和重复ID。
这些是描述性区间，未做多重比较或序贯窥看校正，也未覆盖多次重训随机性。

历史后期使用平台趋势控制分辨率阶段和LR；本包训练器默认固定 `steps` 并定期记录验证，
**没有把简化FM或同源余弦接成自动晋级/停止器**。
选择检查点时同时看独立风格、正确/错误分离、图像质量和新面板确认，不能单凭单次最高分。
