# Z3 默认参数的实验依据

这里的“默认”是既有研究路线的工作起点，不是经大规模盲测证明的全局最优。
所有数字来自本地保存的实际实验记录；本次整理**没有重新训练或重新生成这些数据**。
原始数值、文件SHA与脱敏说明见 [evidence/provenance.json](../evidence/provenance.json)。
[完整数值表](Z3_TABLES.md)由脚本从JSON直接生成，方便核对，另有[推理扫描CSV](../evidence/z3_tuning.csv)。

## 1. 为什么是全层注入、4组共享

最初 SI0 只在最后4层注入，SI1改为第3/11/19/27层，都是13.31M参数、1000步。
分散注入能增加画面变化，但五位画师输出仍趋同；scale4曾导致结构破坏。
随后 AI0 在全部28层注入，保持4组共享；AI1全28层独立参数，约88.81M。
这是“全层共享方案值得保留”的证据，不是“4组已穷举最优”的证据。

固定3内容×5画师的 img2img t=0.85：

| 方案 | 参数约数 | 相对原生风格增益 L | 正确−其他画师平均 D |
| --- | ---: | ---: | ---: |
| SI1 分散4层 | 13.31M | 0.0101 | 0.0082 |
| AI0 全28层、4组 | 13.31M | 0.0641 | 0.0556 |
| AI1 全28层、28组 | 88.81M | 0.0896 | 0.0926 |

AI1容量是AI0约6.67倍，但在低噪声及单内容联合CFG下并未一致领先。
AI0作为成本较低的后续基线。AI0相对SI1还改变了参数复用次数，AI1相对AI0同时改变容量和共享，
不能把结果全部归因于“层数”。指标与条件同源、面板小、单seed，支持条件响应改善，尚非画师质量保证。
[逐内容数据](../evidence/architecture.json)。

## 2. Z0 → Z1 → Z2 → Z3：训练选择

四组都从同一 AI0 step1000 权重及 AdamW 分叉，追加1024步到step2024。
32训练画师、2895目标，global batch16，四卡micro1×累积4，512方图。
底模/编码器冻结，FM-only、参考丢弃10%、AdamW decay0.01、clip1。

| 组 | 单参考比例 | 文本丢弃 | 续训峰值LR | 比较意义 |
| --- | ---: | ---: | ---: | --- |
| Z0 | 50%（其余多参考） | 10% | 1e-5 | 原配方续训 |
| Z1 | 100% | 10% | 1e-5 | 只改单参考 |
| Z2 | 100% | 50% | 1e-5 | 只改文本丢弃 |
| Z3 | 100% | 50% | 1e-4 | 相对Z2只恢复较大峰值LR |

8位适配器未见画师×4案例，常规single分支，差值相对AI0 single：

| 组 | Hit@1 | Δ风格余弦 | Δ内容余弦 | ΔHit pp [画师聚类95%CI] |
| --- | ---: | ---: | ---: | --- |
| Z0 | 12.500% | −0.00546 | −0.00082 | +3.125 [−6.250,+12.500] |
| Z1 | 12.500% | −0.00211 | +0.00103 | +3.125 [+0.000,+9.375] |
| Z2 | 15.625% | −0.00244 | −0.00712 | +6.250 [+0.000,+18.750] |
| Z3 | 12.500% | +0.00941 | −0.01107 | +3.125 [+0.000,+9.375] |

**四组当时均未通过旧晋级门槛**：要求未见命中至少+5pp且区间下限>0，风格增益区间下限>0，
内容余弦下降不超过0.01。不能把Z3写成那轮统计筛选的胜出方案。
后来用户目视偏好Z3 single，并明确风格优先、放宽内容保持限制，于是继续对Z3做推理扫描。
这是一项目标与偏好的更新，旧实验结果没有被追溯修改。

Z3相对Z2唯一训练差异是峰值LR；不能把二者差异归因于“单参考+50%文本丢弃”，因为Z2已有两者。
8位画师的bootstrap不包含多次重训的随机性。
[原始比较](../evidence/zeroshot_comparison.json)、[Z3配置](../evidence/Z3_config.json)、
[Z3逐案例评分](../evidence/Z3_evaluation.json)。

## 3. 为什么推理用 text CFG2 / style guidance5.5 / scale1

固定Z3 step2024，单参考、无画师名、512²、28步Euler、t=0.85；
两组各8已见+8未见画师、每位4案例，共576条记录，128条复用基线、实际新增448张。
以下是同一开发面板的**未见组**，每个候选只改一项：

| 参数 | 风格余弦 | Hit@1 | 内容余弦 |
| --- | ---: | ---: | ---: |
| 原始text5.5/style5.5/scale1 | 0.27577 | 12.500% | 0.76708 |
| text CFG3.5 | 0.30685 | 15.625% | 0.76700 |
| **text CFG2** | **0.31608** | **25.000%** | **0.77454** |
| t=0.80 | 0.28162 | 12.500% | 0.81722 |
| scale0.85 | 0.28418 | 15.625% | 0.78027 |
| style guidance7.5 | 0.30772 | 18.750% | 0.76723 |
| scale1.25 | 0.30720 | 28.125% | 0.76262 |
| scale1.5 | 0.30702 | 12.500% | 0.76635 |

CFG2相对原始：风格+0.04031，95%CI [0.02685,0.05409]；命中+12.5pp，CI [3.125,25.0]pp；
内容均值+0.00746但区间跨零。8位未见画师的风格差均为正，所以优先试用CFG2。
scale1.25有更高Hit@1，但并非风格余弦最高；scale1.5没有继续改善未见命中。
t降到0.80主要改善内容保持，未显示明确的风格收益。

这些比较使用已查看开发集、同源编码器，七项比较未校正多重选择；没有新的画师/内容/seed确认。
不能宣称对所有画师普遍最优，不能将降低CFG和提高scale的单项收益相加。
[完整已见/未见组与区间](Z3_TABLES.md)、[机器可读结果](../evidence/z3_tuning.json)。

## 4. Z3C 与全量检查点不是同一个“Z3版本”

Z3C从Z3权重出发，**新建AdamW**追加2048步，保持单参考、dropout、全层共享架构。
8位未见画师×4内容、text2/style5.5的配对结果：

| 指标 | 原Z3 | Z3C | 差值 [95%CI] |
| --- | ---: | ---: | --- |
| 画师余弦 | 0.30607 | 0.33970 | +0.03363 [0.00871,0.05760] |
| 8画师图库Hit@1 | 31.250% | 46.875% | +15.625pp [−6.250,+34.375] |
| 原始DINO风格余弦 | 0.58245 | 0.56815 | −0.01430 [−0.03271,+0.00343] |
| 源图内容余弦 | 0.77146 | 0.77265 | +0.00120 [−0.01212,+0.01442] |

同源画师分数提升，但其他指标并不一致支持视觉提升。这个图库只有8人，不能与上一轮16人图库的命中率直接比较。
[Z3C训练健康、网格和配对统计](../evidence/z3c_metrics.json)。

后续全量训练从Z3C step2048权重初始化，fresh AdamW，4,314,223目标、41,759画师，global batch128。
全量step12006是后续插件使用的**中间检查点**，不是“统计上最好”的代称。
之后多分辨率任务继承step12006的adapter、AdamW和rank RNG，
新增500步warmup，从约2.6154e-5回升至1e-4；A=512分桶，B=512/768按30/70，C=512/768/1024按20/30/50。
这些分辨率比例和长训练调度属于后续工程选择，不能声称由早期Z0–Z3消融逐项验证。

[全量配置](../evidence/full_config.json)、[早期全量指标日志](../evidence/full_metrics.jsonl)、
[多分辨率配置](../evidence/multires_config.json)是历史证据，里面的本地路径已脱敏，不能直接当可运行配置。
早期日志保留旧平台减半算法；后来改为联合趋势/独立评估，不能拿旧日志推断当前停止规则。

## 5. 为什么后来增加独立 CSD 和固定FM

后期v2用16画师、192生成案例、288固定FM案例，在同一新协议下：

| step | CSD目标相似度 | CSD margin | correct FM / 无style FM |
| --- | ---: | ---: | ---: |
| 26006 | 0.582843 | 0.056696 | 0.992789 |
| 35006 | 0.576837 | 0.064347 | 0.991503 |
| 35733 | 0.566457 | 0.059293 | 0.991399 |

35006相对26006的margin差+0.007650，画师聚类95%CI约[0.000066,0.017295]；
目标绝对相似度却下降，说明单看一个余弦可能误导。
固定FM收益约0.72%→0.85%，仍不能解释成“风格成功率”。
以上不是新旧评估协议间的直接可比数值，也不是所有未来检查点的最终排名。
[完整v2结果与限制](../evidence/eval_v2.json)。

## 6. 本包默认的准确含义

- **架构继承**：256D、8 tokens、width256、4 banks、全层、纯侧路。
- **核心训练参数继承**：单参考、text dropout0.5、reference dropout0.1、peak LR1e-4。
- **推理工作起点继承**：Krea2 text2、style5.5、scale1；img2img t0.85。
- **新用户示例约定**：从零训练2048步、20步warmup、缓存数据入口。这不是历史checkpoint复现声明。
- **继续测试的变量**：容量、数据覆盖、分辨率、独立指标与多seed；见[参数地图](PARAMETERS.md)。
